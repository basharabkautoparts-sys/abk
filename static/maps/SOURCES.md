# World map geometry

Natural Earth, 1:110m land polygons. Public domain.
- Dataset: https://www.naturalearthdata.com/downloads/110m-physical-vectors/110m-land/
- GeoJSON: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson
- Terms: https://www.naturalearthdata.com/about/terms-of-use/

Downloaded 2026-09-18. Projected with x = (longitude + 180) × 1000 / 360,
y = (85 − latitude) × 1000 / 360. Antarctica omitted; coordinates rounded to
2 decimal places. The viewBox is 0 0 1000 420. Export links use approximate
locations and illustrate destination coverage, not actual shipping lanes.
